## 🧭 Conventions

Examples use Python 3.11+ and commands from the repository root unless stated otherwise. `myapp` is a project you create. `DEVICE_ID` is a placeholder for your device serial.

✅ means completed. 🧪 means validation required. 📋 means planned work. A planned feature is not an available API.
