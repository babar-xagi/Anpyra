# ➡️ Original Arrow Icon

`arrow.png` is an original transparent 96×96 raster arrow created from a simple polygon for this example. It is covered by the repository's [Apache-2.0 license](../../../LICENSE). No third-party artwork is included.

The Button icon pipeline normalizes the image and applies the declared 24 dp bounds, end placement and white tint at runtime. The application can supply another local raster file; this asset is not a backend fallback.
