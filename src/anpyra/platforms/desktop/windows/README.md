# 🪟 Future Windows Backend

**Status: reserved, not implemented.** This package currently contains only a package marker and this ownership note. Anpyra running on Windows currently builds Android APKs; it does not generate native Windows applications.

Future Windows UI bindings, executable generation, target configuration and packaging belong here. Reuse shared source/project rules from `anpyra.common`. Build host/toolchain and artifact contracts remain to be designed and validated.

See [native architecture](../../../../../docs/developer_guide/native_platforms.md) and [phase 11](../../../../../docs/roadmap.md).
